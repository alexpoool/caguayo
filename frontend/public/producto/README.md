# Marca del producto (ITEMLI)

Assets fijos del software. Son los mismos en todas las instalaciones.

Falta por colocar (pídelo a quien generó el logo y sueltalo aquí):

- `itemli-logo.png` — logo del producto (el del círculo azul/violeta).
  Se usa en el Login cuando exista; hasta entonces se muestra el
  nombre en texto (`ITEMILI`).
- `favicon.ico` (+ `favicon-16x16.png`, `favicon-32x32.png`,
  `apple-touch-icon.png`) — actual cuando se genere.

Después de colocarlos, actualizar `index.html` (`<title>ITEMLI</title>`,
`<link rel="icon">`) para apuntar a esta carpeta.
